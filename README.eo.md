## Strukturo

`kern/` kerna kerno · `sys/` kernaj kapdosieroj kaj tipoj · `arch/` maŝindependa kodo · `dev/` peliloj · `scsi/` SCSI-stako · `net/`, `netinet/`, `netinet6/` retkodo · `ufs/`, `nfs/`, `ntfs/`, `msdosfs/`, `tmpfs/`… dosiersistemoj · `uvm/` virtuala memoro · `crypto/` · `conf/` kernaj agordodosieroj.
